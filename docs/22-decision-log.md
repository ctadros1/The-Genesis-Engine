## Status Vocabulary

- Accepted product direction: explicit user choice; implementation details remain flexible.
- Proposed technical baseline: recommended but must pass a stated validation gate.
- Deferred: deliberately postponed; no implementation commitment.
- Superseded: retained for history; do not apply to new worlds.
