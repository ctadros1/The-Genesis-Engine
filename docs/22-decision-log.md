# Decision Log

## Status Vocabulary

- Accepted product direction: explicit user choice; implementation details remain flexible.
- Proposed technical baseline: recommended but must pass a stated validation gate.
- Deferred: deliberately postponed; no implementation commitment.
- Superseded: retained for history; do not apply to new worlds.

## Entry Template

Record: ID, date, status, context, options, choice, evidence, performance impact, operational/security impact, compatibility effect, owner, and explicit revisit condition. Link the associated ADR when the decision has broad or durable consequences.

## Rule-Change Ledger

For each simulation-policy change, record old config/schema hash, new hash, affected formulas/traits, expected effect, migration/replay policy, validation tests, benchmark/scenario result, and whether existing worlds branch or remain on legacy rules.
